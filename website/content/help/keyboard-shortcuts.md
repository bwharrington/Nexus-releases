# Keyboard shortcuts

Common shortcuts in Nexus. On macOS, use `Cmd` in place of `Ctrl` where the app follows platform conventions.

## File operations

| Shortcut | Action |
| -------- | ------ |
| `Ctrl+N` | New file |
| `Ctrl+O` | Open file |
| `Ctrl+S` | Save file |
| `Ctrl+Shift+S` | Save all files |
| `Ctrl+W` | Close current file |

## Editing

| Shortcut | Action |
| -------- | ------ |
| `Ctrl+Z` | Undo |
| `Ctrl+Y` | Redo |
| `Ctrl+Shift+Z` | Redo (alternative) |
| `Ctrl+B` | Bold |
| `Ctrl+I` | Italic |
| `Tab` | Insert 4 spaces |

## Navigation

| Shortcut | Action |
| -------- | ------ |
| `Ctrl+E` | Toggle Edit / Preview mode |
| `Ctrl+F` | Open Find panel (Find tab) |
| `Ctrl+H` | Open Find panel (Replace tab) |
| `Ctrl+G` | Open Find panel (Go to Line) — Edit only |
| `Ctrl+,` | Open Settings |
| `Enter` | In Find: Find Next; in Go to Line: Go |
| `Escape` | Close Find / Replace / Go to Line panel |

## List editing

When editing lists, `Enter` continues the list:

- Numbered lists increment (`1.` → `2.` → `3.`)
- Bulleted lists continue with the same bullet
- Task lists create a new unchecked task (`- [ ]`)

## AI

| Shortcut | Action |
| -------- | ------ |
| `Ctrl+Shift+A` | Open / close Nexus AI dialog |
| `Enter` | Send message or submit edit (in AI dialog) |
| `Shift+Enter` | New line in AI dialog input |

### AI Edit mode navigation

| Shortcut | Action |
| -------- | ------ |
| `J` or `↓` | Next change |
| `K` or `↑` | Previous change |
| `Enter` or `Y` | Accept current change |
| `Backspace` or `N` | Reject current change |
| `Ctrl+Shift+A` | Accept all changes |
| `Escape` | Cancel diff session |
