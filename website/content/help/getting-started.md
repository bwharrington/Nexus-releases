# Getting started

Install Nexus from the latest public release and open your first document in a few minutes.

## Download and install

1. Open the [latest release](https://github.com/bwharrington/Nexus-releases/releases/latest).
2. Download **`Nexus-Setup.exe`** (Windows installer).
3. Run the installer and launch Nexus.

Markdown and reStructuredText files can open in Nexus by double-click after install. Other supported types are available via **Open with → Nexus**.

## Open a file

- **File → Open** or `Ctrl+O` to open an existing document.
- **File → New** or `Ctrl+N` for a blank tab.
- Use the **File Directory** panel on the left to browse project folders and open multiple files.

## Edit and preview

For Markdown, RST, CSV, and SVG, switch between **Edit** and **Preview** (or table view for CSV) with `Ctrl+E` or the view toggle in the toolbar.

## Save your work

- `Ctrl+S` saves the current tab.
- `Ctrl+Shift+S` saves all open files.
